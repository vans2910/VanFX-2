Van Pips Admin

Secure backend admin

This page is served from the backend only. Access is restricted to administrators via HTTP Basic authentication or admin API credentials.

Use your admin email and password to access this page.

Administrator actions

  • POST /api/auth/login — obtain an access token
  • GET /api/admin/users — list all registered users
  • PATCH /api/admin/users/:id/subscription — approve or revoke subscriptions
  • POST /api/signals — publish a new trading signal
  • POST /api/videos — upload a new video lesson
  • POST /api/free-content — publish free market content

Notes

Only authenticated admin users can open this page. If your access fails, refresh and re-enter your credentials.

This backend route is not linked to the public website and cannot be reached from the user-facing UI.
